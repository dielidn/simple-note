# Simple Notes

Заметки-карточки: максимум 14 штук, срок жизни 7 дней, свежая жёлтая → старая серая.

Веб-версия — один файл [`index.html`](index.html) в корне: без зависимостей,
без сборки, без облака. Данные лежат в `localStorage` этого устройства,
резервная копия — экспорт/импорт JSON (слияние по `id`).

Открыть: просто откройте `index.html` в браузере или зайдите на GitHub Pages
этого репозитория; на телефоне добавьте на домашний экран.

Правила и принятые решения — в [CLAUDE.md](CLAUDE.md).
