# Simple Notes

Заметки-карточки. Максимум 14 штук, срок жизни 7 дней, свежая жёлтая → старая серая.

## Правила (менять только осознанно)

- `MAX_NOTES = 14`. Пятнадцатая молча вытесняет самую старую.
- `LIFETIME = 7 дней` от `createdAt`. Редактирование срок **не продлевает** —
  если понадобится обратное, поменять `createdAt` на `updatedAt` в проверках возраста.
- Чистка запускается при старте, при возврате на экран и раз в 30 секунд.
  Отдельный фоновый процесс не нужен: пользователь не должен увидеть просроченную карточку.
- Выцветание — **smoothstep** `x*x*(3-2x)`, не линейное. Линейное начинает гасить
  карточку сразу после создания и выглядит вяло; smoothstep держит цвет первые
  ~2 дня, основное посерение приходится на середину недели.
- Цвета: светлая тема `rgb(255,217,84)` → `rgb(229,229,234)`,
  тёмная `rgb(102,82,23)` → `rgb(44,44,46)`.

## Модель данных

Одинаковая во всех версиях, менять только синхронно:

```json
{ "id": "uuid", "text": "…", "createdAt": "ISO-8601", "updatedAt": "ISO-8601" }
```

Плоская схема с ISO-датами выбрана специально, чтобы Swift, JS и бэкенд
читали один и тот же JSON без конвертеров.

## Что уже сделано

| Вариант | Состояние |
|---|---|
| `ios/` SwiftUI, iOS 17+ | работает локально, синхронизации нет |
| `web/` PWA | **текущая версия**, localStorage, экспорт/импорт JSON |
| `worker/` Cloudflare + KV | написан и протестирован, не развёрнут |
| `extension/` Chrome MV3 | написан, не подключён |

Сейчас в работе локальная веб-версия: без облака, только это устройство.
Хостится на GitHub Pages, `index.html` строго в корне репозитория.

Вся логика и стили по-прежнему в `index.html`. Рядом лежат только файлы,
которые обязаны быть отдельными: `apple-touch-icon.png` (180×180),
`icon-512.png` и `manifest.webmanifest` — иначе iOS не ставит иконку
на домашний экран (см. «Подводные камни»).

## Решения, которые уже приняты

- **Отказ от облака** ради простоты. Код бэкенда сохранён, но не используется.
  Если возвращаться — там слияние last-write-wins по `updatedAt` плюс надгробия
  `{id, deletedAt}`: без них удалённая на одном устройстве заметка воскресает
  с другого, а вытесненные лимитом 14 ходят по кругу.
- **Экспорт в JSON обязателен**, потому что localStorage может быть стёрт
  Safari, сменой устройства или удалением иконки. Импорт сливает по `id`.
- **Хранилище за адаптером** с падением в память: приватный режим Safari
  блокирует localStorage, приложение не должно ломаться.

## Подводные камни

- Safari чистит localStorage у сайтов после 7 дней простоя. На приложение,
  добавленное на домашний экран, это не распространяется.
- В артефактах и части песочниц localStorage недоступен — отсюда адаптер.
- Если добавляете service worker, поднимайте версию кэша при каждой правке,
  иначе телефон продолжит отдавать старую копию.
- GitHub Pages на бесплатном тарифе требует публичного репозитория.
- На iOS слой вёрстки **не сжимается** под клавиатуру. Шторка с
  `position: fixed; bottom: 0` уезжает под неё, а Safari вдобавок сам
  прокручивает страницу к полю ввода и утаскивает шторку из виду. Лечится
  двумя вещами сразу, по отдельности не работает: переменной `--kb`
  (`innerHeight - visualViewport.height - offsetTop`) в `bottom` шторки и
  высоте поля, и блокировкой прокрутки `body.locked` на время шторки.
  Блокировка обязана запоминать `pageYOffset` и возвращать его при закрытии,
  иначе список прыгает в начало.
- `apple-touch-icon` у Safari обязан быть **PNG-файлом**: ни SVG, ни `data:`
  он не принимает. Отсюда отдельные PNG вместо иконки внутри HTML.
- Пути к иконкам и манифесту — **только относительные**. Проект на Pages
  отдаётся по `/simple-note/`, в корне домена ничего нет, поэтому автоподхват
  `/apple-touch-icon.png` не срабатывает, а `/icon-512.png` даст 404.
- Манифест обязан быть файлом, а не `data:`-URI: у `data:` нет базового URL,
  и относительные `src` иконок внутри него не разворачиваются.
- iOS обрезает иконку своей маской и не любит прозрачность, поэтому PNG —
  без альфа-канала и без заранее скруглённых углов, рисунок на всю площадь.
  Содержимое держать внутри центральных ~80%: этого же требует `maskable`
  на Android.

## Стиль

Минимализм в духе iOS: системные шрифты, `env(safe-area-inset-*)`,
шторки снизу, тёмная тема через `prefers-color-scheme`. Никаких зависимостей,
никаких сборщиков — обычный HTML, CSS и JS без модулей.

Поверх этого — матовый soft-UI: серая подложка, приподнятые панели с мягкой
рассеянной тенью, фрост на шапке и шторках, утопленные поля. Держится на
переменных `--lift` (тень), `--edge` (светлая кромка), `--inset` (утопление),
`--panel` / `--chrome` (полупрозрачные поверхности) — правится в одном месте,
не по селекторам.

Была попытка сделать это глянцевым скевоморфизмом — блики, тиснение текста,
зерно на фоне. Выглядело грязно и устарело, откатили. Не возвращать:

- **Никакого глянца.** Поверхности матовые. Градиентный блик поверх карточки
  ещё и сдвигает воспринимаемый цвет, а цвет здесь несёт смысл.
- **Никакого тиснения.** `text-shadow: 0 1px 0 white` на заголовках и тексте —
  главный признак iOS 6.
- **Никакого зерна.** Шумовая плёнка поверх фона читается как грязь.
- Глубина берётся из мягкой тени с большим размытием и малым сдвигом плюс
  полупрозрачные слои, а не из фасок и бликов.

- Фон карточки ставит JS через `style.backgroundColor`. Шорткат
  `style.background` не использовать: он сбрасывает `background-image`,
  и любой будущий слой поверх карточки молча пропадёт.
- Тёмная кнопка (`--ctl`) в тёмной теме инвертируется в светлую: это
  единственный элемент максимального контраста, он же главное действие.
- Полупрозрачные поверхности включаются только внутри
  `@supports (backdrop-filter)`. Без фроста остаются плотные `--*-solid`,
  иначе текст ляжет на просвечивающую подложку.
- Поле ввода без рамки и заливки: текст лежит прямо на шторке. Рамку не
  возвращать — на устройстве она читается как чужеродная кайма.

Анимации: появление карточек (каскадом на первой отрисовке, поштучно для
новых), уход удаляемой карточки, выезд шторок, проявление пустого экрана.
Два правила:

- `.card.enter` использует `animation-fill-mode: backwards`, а не `both`:
  при `both` конечный `transform` анимации перебивает `:active`, и нажатие
  перестаёт давать отклик.
- `render()` отсекается по слепку видимого состояния (`lastSig`). Без него
  `pageshow` и `focus` перерисовывают сетку сразу после старта и сносят
  анимацию, а раз в 30 секунд DOM пересобирается впустую. **В слепок обязано
  входить всё, что видно на карточке** — id, цвет, подпись и текст: забудешь
  текст, и правка заметки не доедет до сетки.
